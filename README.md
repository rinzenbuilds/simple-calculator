# 🧮 Simple Calculator

A beginner-friendly calculator built in Python. It performs basic arithmetic operations using user input.

## Features
- Addition
- Subtraction
- Multiplication
- Division


## Technologies Used
- Python 3

## How to Run

1. Clone this repository
2. Open the project in VS Code
3. Run:

```bash
python calculator.py
```
